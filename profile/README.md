### Evgeny Padezhnov — tools for running AI agents for real

Small, readable add-ons for [Claude Code](https://code.claude.com), built for a working fleet of agents and published when they hold up.

| | |
|---|---|
| [**claude-code-mods**](https://github.com/padezhnov/claude-code-mods) | `unattended` — breaks failing-call loops and resumes after API errors · `anti-slop` — no narrating comments or stock phrases · `native-edits` — file changes through Edit, so `/rewind` can undo them |

```
/plugin marketplace add padezhnov/claude-code-mods
```

Every mod: no network, no telemetry, a few small files you can read before installing.
